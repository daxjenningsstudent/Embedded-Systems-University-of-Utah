# Embedded-Systems-University-of-Utah
Embedded systems projects completed as part of ECE 5780 at the University of Utah.
Projects focus on embedded C development, STM32 microcontrollers, peripheral interfaces, hardware control, and debugging.


DC Motor Driver:
Designed and developed a DC motor driver project spanning the full hardware and firmware development process

- Designed the circuit schematic
- Designed the PCB layout
- Fabricated and assembled the PCB
- Developed embedded C firmware for an STM32F072 microcontroller
- Implemented GPIO and motor-control functionality
- Tested and debugged the completed system
(The Motor Driver folder just contains the source files with code that I wrote for the project.)

- Lab 5: I2C
